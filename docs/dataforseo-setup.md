# DataForSEO setup — private SEO dashboard

The admin dashboard at `/admin/search-console` has a **Rank tracking (DataForSEO)** tab. Signed-in administrators also see it below the Google connection prompt while Search Console is still unconnected. It uses the owner's own DataForSEO account. All calls are made server-side from the existing Search Console Vercel function. Credentials are never sent to the browser, logged, or returned in responses.

> DataForSEO data comes from a third party: live Google SERP snapshots plus DataForSEO Labs database estimates. It is **not** Google Search Console data. Every dashboard section shows its source, retrieval time, location, language, device, cost and whether it came from cache.

## 1. Get the API credentials

1. Sign in at https://app.dataforseo.com/.
2. Open **API Access** (https://app.dataforseo.com/api-access).
3. Copy the **API login**, which is your account email.
4. Copy the **API password**. It is generated by DataForSEO and differs from your sign-in password.
5. Recommended: set a **daily spend limit** in the DataForSEO account settings as a second cost guard.

## 2. Add them to Vercel

1. Go to Vercel → project **ekl2026-envod-kingdom** → **Settings** → **Environment Variables**.
2. Add the following variables. Tick **Production** and **Preview**, and mark both credentials **Sensitive**.
   - `DATAFORSEO_LOGIN`: the API login.
   - `DATAFORSEO_PASSWORD`: the API password.
   - `DATAFORSEO_MONTHLY_BUDGET_USD` (optional): for example `5`. This is the dashboard's hard monthly cap.
3. Environment variables only apply to new deployments. After the owner approves the merge, redeploy, or let the next `main` deployment pick them up.

Notes:

- Preview deployments can call DataForSEO. However, the Google admin sign-in only works on production, because `GSC_REDIRECT_URI` is the production callback. The tab is therefore normally used on `https://www.envodkingdom.net/admin/search-console`.
- Stored data lives in the private Blob store (`BLOB_READ_WRITE_TOKEN`) under `envod-private/dataforseo/`. This covers history, cache, usage ledger, tracking config and locations. Without Blob on Vercel, the routes fail closed instead of using the ephemeral filesystem.

## 3. Verify locally (optional)

Create `artifacts/envod-kingdom/.env.local`. The file is git-ignored; never commit it. Use `.env.example` as the template:

```
DATAFORSEO_LOGIN=...
DATAFORSEO_PASSWORD=...
```

Then, from `artifacts/envod-kingdom`:

```
pnpm run dataforseo:verify                    # free: authenticates via appendix/user_data, shows balance
pnpm run dataforseo:verify -- --minimal-paid  # + one live Google SERP request ("envod kingdom", Saudi Arabia, desktop, depth 50)
```

The script prints only "set"/"MISSING" for the variables, never their values. Local results are stored in `artifacts/envod-kingdom/.private-data/dataforseo/`, which is git-ignored.

## 4. Cost controls built in

- **Free:** the connection check (`appendix/user_data`, cached 60 s) and the locations list (`serp/google/locations`, `dataforseo_labs/locations_and_languages`, cached 30 days).
- **Estimate first:** every paid action shows an estimate. Nothing is charged until **Confirm & run** is pressed, and the server rejects paid calls that lack `confirm: true`.
- **Monthly cap:** `DATAFORSEO_MONTHLY_BUDGET_USD` (default $5) is checked before each paid request. Actual costs reported by DataForSEO are recorded in a monthly ledger, shown in **API usage**.
- **Caching:** SERP results for 12 hours; Labs data for 7–14 days. A repeat of the same request within the TTL is free.
- **Duplicate protection:** identical in-flight requests are merged. Only one rank check can run at a time, and each batch is locked.
- **Rate limiting:** 240 dashboard requests per 5 minutes, and 60 paid requests per 5 minutes, per IP.
- **Never scheduled:** nothing runs in the background or on a schedule. Every paid call is started by the administrator.

## 5. Expected costs (estimates, based on DataForSEO's published pricing; check your account's price list)

| Action | Approximate cost |
|---|---|
| Connection check, locations | Free |
| Rank check: 1 keyword × 1 location, live, depth 50 | ≈ $0.01 |
| Rank check: the 23 default keywords × Saudi Arabia | ≈ $0.23 |
| Rank check: 23 keywords × Saudi Arabia + Riyadh + Jeddah + Dammam | ≈ $0.92 |
| One Labs request (ranked keywords, domain overview, competitors, keyword overview, suggestions, related) | ≈ $0.012 + $0.00012 per returned item (typically $0.013–$0.04) |

DataForSEO's minimum top-up is $50. New accounts receive a small trial credit.

## 6. Competitors

These are listed in the dashboard under **Configuration → Competitor domains**. The defaults live in `artifacts/envod-kingdom/server/dataforseo/config.ts`, and the saved copy is in private storage. Only `verified` and `likely` domains are matched in SERPs or sent to Labs. `unconfirmed` competitors are skipped until the owner supplies the official domain.
