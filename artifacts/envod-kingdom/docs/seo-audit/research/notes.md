## Findings Log

### English search intent
Observed public service-page wording centers on exhibition/event logistics, trade-show cargo, freight modes, customs/temporary admission, venue/booth delivery, and post-event returns. These observations do not establish search volume, rank or demand.

### Arabic search intent
«لوجستيات المعارض والمؤتمرات» was directly observed on a freight-provider page. Exact usage of «شحن بضائع المعارض» was not found in the sample. Keep event organization and booth design distinct from freight intent.

### Regulation, events and competition
ZATCA’s ATA Carnet service is pre-approval, not a release guarantee. The current event page already avoids claiming ENVOD is appointed at listed events. Current official calendars showed conflicting/outdated snippets for Global Health and Foodex; the live page does not publish edition dates.

### Implementation
Added GCC cross-links, corrected the Malham venue name, consolidated Jeddah venue aliases, and clarified the bilingual event-planning caveat. The existing qualified phrase, bilingual content, quote prefill and service-specific questions were retained.

## Conflicts & Open Questions
- Search Console/Keyword Planner access and the Vercel project environment variables are unavailable; no real demand, rankings, clicks, impressions, CTR or URL Inspection metrics can be reported.
- ZATCA launch material uses “Council of Saudi Chambers”; ICC’s current directory uses “Federation of Saudi Chambers.” Do not publish a legal equivalence without confirmation from the Federation.
- The Foodex official English page and homepage search result show different edition listings; confirm before publishing a multi-city schedule.
- The current Global Health organizer page says no in-person 2026 exhibition; older official search results still show the former 2026 dates. Do not use the stale schedule.
- Specific venue freight access, delivery slots, loading procedures and move-in/out rules were not found; confirm with the event/venue for each booking.
- A Vercel production deployment of the integrated code reached READY; public English/Arabic service routes returned 200 and the English page showed the qualified phrase and corrected venue labels. The Search Console session is unconfigured; Resend delivery remains unverified because no Vercel environment variables are configured.
