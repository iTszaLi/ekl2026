# Search record and unresolved official-source leads

Research date: 17 October 2026. Free public search only; no paid search or databases.

## Query angles run

Four distinct query angles were used, including an Arabic-language query:

1. `site:zatca.gov.sa import customs clearance documents Saudi Arabia`
2. `site:mawani.gov.sa Jeddah Islamic Port King Abdulaziz Port Dammam Riyadh Dry Port`
3. `site:tga.gov.sa Saudi GCC road transport freight conditions`
4. `الجمارك السعودية المستندات المطلوبة للاستيراد فسح`

The public search endpoints returned inconsistent or irrelevant result pages in this environment. Follow-up direct checks used ZATCA's official sitemap and the TGA sitemap/portal to locate official pages. This was source discovery, not evidence that a search result is itself authoritative.

## Official pages located but not independently read as source evidence

1. **ZATCA, “Mandatory customs declaration” (2025 announcement)**  
   https://zatca.gov.sa/en/MediaCenter/News/Pages/mandatory-customs-declaration-2025.aspx  
   Official site URL was confirmed in ZATCA's sitemap; the page was not read, so make no claim from it.

2. **ZATCA, “Importers registration feedback” (2025 announcement)**  
   https://zatca.gov.sa/en/MediaCenter/News/Pages/importers-registration-feedback-2025.aspx  
   Official site URL was confirmed in ZATCA's sitemap; the page was not read.

3. **ZATCA, Brokers Guideline (Arabic and English versions listed in the official sitemap)**  
   https://zatca.gov.sa/en/RulesRegulations/Taxes/Pages/Customs%20Clearance/Brokers-Guideline.aspx  
   https://zatca.gov.sa/ar/RulesRegulations/Taxes/Pages/Customs%20Clearance/Brokers-Guideline.aspx  
   Read the Customs Journey page above for the broker authorization facts rather than inferring legal duties from the guideline title.

4. **Mawani, Jeddah Islamic Port official-page lead**  
   https://mawani.gov.sa/en-us/Ports/Pages/JeddahIslamicPort.aspx  
   Direct requests to Mawani returned HTTP 405 / an access-block response in this environment, including its homepage. No port specifications were extracted or used as facts.

5. **Mawani, King Abdulaziz Port Dammam official-page lead**  
   https://mawani.gov.sa/en-us/Ports/Pages/KingAbdulazizPortDammam.aspx  
   Direct requests returned the same HTTP 405 block; page content and current operating details remain unverified.

6. **TGA, regulations and legislation index**  
   https://tga.gov.sa/ar/regulations  
   Page read; it identifies land, maritime, and rail regulatory sectors, but the response did not expose a specific GCC road regulation.

7. **FASAH platform (official ZATCA service link)**  
   https://fasah.zatca.gov.sa/  
   Linked by ZATCA's Import Instructions. Platform access/transactional requirements were not independently checked.

## Access note

Mawani was attempted as a direct official source, but its HTTP 405 response means the service pages are leads, not corroborating evidence. Port descriptions and route-specific capacities, services, operating schedules, terminal/operator details, and current status should not be asserted from this research without another official accessible source.
