# Evidence: Official Saudi exhibition and event calendar pages

**Fetched:** 17 October 2026

## SCEGA — national events schedule

- **Source:** Saudi Conventions and Exhibitions General Authority (SCEGA)
- **Public events schedule URL:** https://www.scega.gov.sa/h-events-list
- **Legacy MICE calendar URL:** https://www.scega.gov.sa/ar/EServices/Pages/MICECalendar.aspx
- **Legacy calendar PDF URL:** https://www.scega.gov.sa/Documents/Events23Ar.pdf
- **Source tier:** Tier 1 — Saudi government authority

The current SCEGA site exposes an “Events Schedule” route (`/h-events-list`). The route is an application-rendered listing; the page shell does not contain the event records as static HTML. The official legacy MICE-calendar endpoint currently returns the authority's application shell. The linked calendar PDF is explicitly a 2023 calendar and is historical, not evidence for 2026 event dates. Treat SCEGA's live schedule as the authoritative government discovery point, but verify each event's date and venue with the current listing and organizer before booking.
