# AI answer visibility monitoring checklist

This is a repeatable question set, not a claim that an AI system currently cites ENVOD KINGDOM. Run it from a Saudi-located browser in English and Arabic, save the date, exact prompt, provider/model, location setting, cited sources and whether ENVOD appears. Compare monthly; do not treat one response as a ranking.

## Record for each test

- Test date and local timezone
- AI/search provider and model or feature, if disclosed
- Searcher location and language setting
- Exact prompt and unedited response
- Whether ENVOD was named, linked, or cited
- Which page or external source was cited
- Whether each factual statement was correct
- Comparison with the previous test, without inferring causality from a single result
