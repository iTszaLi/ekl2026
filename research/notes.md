## Findings Log

### Production and local build

The local build contains 92 routes (46 EN and 46 AR). The public sitemap contains 43 English routes; all 43 returned HTTP 200. The 46 local Arabic routes and three local legal routes omitted from the sitemap returned HTTP 404 when checked on 2026-10-21. The public sitemap contains no `hreflang` alternates and repeats a 2026-07-06 `lastmod`. The local generated build has reciprocal EN/AR metadata; local correctness does not establish production indexing. See the direct route audit CSVs and the primary report.

Local static checks found 0 broken internal links, 0 broken fragments, 0 missing image files, 0 missing alt text, 0 duplicate title/description groups, and 346 image tags without explicit dimensions. The 510 local JSON-LD blocks parsed syntactically. These checks do not replace browser, field-performance, schema eligibility or production verification.

### Keyword evidence and integrity

The project master now has 2,935 rows (1,460 EN / 1,475 AR) and 35 fields. The pre-import 1,306 records and their original 19 field values remain unchanged; an exact dated backup is retained. The historic 1,014-row baseline and 292-row delta remain intact.

The uploaded 2,400-row bilingual corpus is candidate data with volume/difficulty marked “Not measured.” A route-aware import appended 1,629 records: 771 same-route records were matched without re-appending, 8 phrase/language records already mapped elsewhere were appended and flagged, and 1,621 new phrase/language pairs were added. All 2,400 source rows remain in the import crosswalk. The expanded master has 8 exact cross-route duplicate groups and no same-route exact duplicates; no records were removed. The uploaded draft URL differed from the audited existing route for 1,550 rows, mainly because Arabic records pointed to English paths or slugs differed; corrected existing routes and original drafts are recorded in the crosswalk. The 2,395-row Keyword Planner CSV contains only seed phrases and is not a results export. No GSC, paid Planner, rank-tracker, backlink, lead-attribution or Core Web Vitals export was supplied.

### Saudi search landscape and competitors

Fresh web-search requests returned HTTP 402. Direct Bing fallback samples were noisy and not reliably Saudi-localized; they were not used to make ranking or demand claims. Five delegated research areas encountered the same search-access failure. The report therefore uses dated source captures from 2026-10-17/18 as limited qualitative context, not current rank evidence.

The saved sample includes directly inspected DSV Saudi/service pages and dated captures for SAL, Saad Logistics, GBE and SMI; remaining competitors are discovery leads or snippets. This is not a complete competitor census, SERP share analysis or backlink audit.

### Customs, ports, exhibition and ATA

ZATCA import instructions and customs-journey guidance were accessible and support conditional, cargo-dependent document explanations and the distinction between importer obligations and authorized broker procedures. ICC and Saudi references support the distinction between ATA coordination and issuance/acceptance. These sources do not prove ENVOD licensing or guarantee release times.

Mawani Jeddah/Dammam direct requests returned HTTP 405; current terminal-specific facts remain open. Avoid copying competitor certifications, fleet, guarantees, terminal access, memberships, client identities, partnerships or venue work without ENVOD evidence.

### Search engines, AI and local trust

Accessible Google guidance supports ordinary crawl/index eligibility, visible useful content and accurate structured data; it does not promise ranking or AI citations. OpenAI documentation distinguishes search crawling from model-training crawling. IndexNow documentation was reviewed, but no account, key or submission evidence was available. Bing Webmaster documentation access was incomplete, and the attempted AI Performance URL returned HTTP 404.

The inspected production `robots.txt` allows all crawlers by wildcard. The local robots file explicitly names several search/AI crawlers; no Grok-specific rule was found in the inspected file. No Business Profile or local-citation export was accessed; branch/contact-location labels remain user-provided until supported by current location evidence.

### Claim controls

The claim matrix labels owner-approved wording separately from independent documentation. The owner selected 50+ fleet vehicles, shipment tracking available to 100%, 24/7 customer support and a 98% on-time rate. These remain owner-attested, without calculation methods or supporting records in this research. The prior 99.8% figure is superseded by that selection. Other old metrics are not treated as newly reaffirmed. Regulatory names must describe document preparation/coordination where applicable, not ENVOD certification.
