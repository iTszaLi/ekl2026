# Content Gap & Page Architecture

## Existing foundation

ENVOD already has a dedicated English exhibition-logistics page and a corresponding Arabic URL. The live page covers international freight, customs-document support, ATA Carnet enquiries, venue delivery, on-site planning and return/re-export. It uses qualified scope language and includes the phrase “leading exhibition logistics providers in KSA” as a comparison statement, not as an unverified superlative. The correct current URLs are:

- English: https://www.envodkingdom.net/services/exhibition-logistics
- Arabic: https://www.envodkingdom.net/ar/services/exhibition-logistics

Both currently return 200, self-canonicalize and list reciprocal EN/AR alternates. Preserve these URLs; do not create a competing “exhibition-event-logistics” page from an old keyword mapping. [R06](13_SOURCE_REGISTER.md#r06) [R07](13_SOURCE_REGISTER.md#r07)

## Recommended authority cluster

Keep the exhibition service page as the primary transactional hub. Add or expand supporting resources only when they answer a distinct user task and can be written accurately:

1. **Exhibitor shipping checklist for Saudi Arabia:** cargo list, dimensions/weights, origin, timing, venue access, crate/packing details, temporary-import intent, outbound return plan.
2. **Saudi ATA Carnet and temporary admission guide:** what a Carnet is, goods/use eligibility, documentation and party roles, who issues it, ZATCA process references, exceptions and where to confirm current rules. ENVOD should describe coordination/enquiries, not claim to issue Carnets.
3. **Post-event return and re-export planning:** close-out inventory, deadlines, carrier bookings, customs-document handoff and return destination confirmation.
4. **Venue delivery planning:** delivery windows, badges/access, unloading arrangements, booth handoff and local contractor coordination. Keep examples factual and avoid implying official venue appointments.
5. **City guidance, only if materially distinct:** Riyadh, Jeddah, Dammam/Eastern Province and Jubail content should explain real route, venue or partner arrangements. Do not claim branches or local teams without evidence.

## Information architecture and internal links

- The existing exhibition service page remains canonical and the only primary page for “exhibition logistics company/service in Saudi Arabia” intent.
- Support it with original resources linked from the page; each resource should link back to the service page and relevant customs, ATA Carnet, freight, packaging/crating and quote pages where the relationship is useful.
- Create equivalent Arabic resources with equivalent facts and source links. Preserve Arabic hreflang and do not machine-translate legal/customs nuance without review.
- Keep event/venue names as examples to research, not as proof of ENVOD participation. The live page currently makes that distinction. [R06](13_SOURCE_REGISTER.md#r06)

## Keyword handling

The 100 English/Arabic exhibition phrases in the supplied master file are candidate ideas with heuristic priorities and estimated intent; volume and difficulty were not measured. The separate 25 Search Console query rows are user-exported observations without a visible date range. See the 125-row CSV and do not treat the candidate count as search demand. [R17](13_SOURCE_REGISTER.md#r17) [R13](13_SOURCE_REGISTER.md#r13)

Avoid repeating “best/leading” variants or creating city doorway pages. Build useful content for shipment tasks first; measure query/page groups on a consistent date window before revising metadata or creating further landing pages.
