## Potential explanations to test—not conclusions

1. **Intent ambiguity:** “Best” plus a city may invite comparisons, while “exhibition logistics” can also refer to venues, organizers, events, stand construction or logistics technology. Test provider-specific and task-specific wording (shipment, customs, ATA Carnet, return freight) separately.
2. **Page-level authority:** Dedicated competitor event pages may answer a broader set of exhibition tasks. This is content evidence, not a rank explanation.
3. **Local relevance:** Google local results depend in part on relevance, distance and prominence; the searcher’s exact location matters. No map grid or verified competitor GBP set is available. [R31](13_SOURCE_REGISTER.md#r31)
4. **Index selection:** The October indexing report lists 50 crawled/discovered-not-indexed URLs. This deserves URL inspection, but the current live crawl shows no sitemap-page 404s.
5. **Authority / links:** No GSC Links export or backlink dataset was supplied. No link-based explanation can be supported.

## Minimum evidence to close the ranking question

- The original screenshot or a new dated capture with query, exact result URLs, device, language, searcher location, signed-in state and full AI citations.
- Same-period GSC Pages and Queries exports for the verified domain property, comparing equal date windows; include country/device filters and Search appearance.
- URL Inspection for the actual exhibition URLs and excluded examples.
- A repeatable local rank grid or search provider with documented location settings; do not infer a national ranking from one user search.
